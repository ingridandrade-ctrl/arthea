# Ferramentas

> Rastreamento de vendas do WhatsApp para Meta Ads

## Lovable

Hospeda o painel da agência, o banco do projeto, o login e as funções do servidor que recebem o webhook, calculam o evento e enviam ao Meta.

## RD Station CRM

Fonte dos dados: etapa da oportunidade, valor, telefone e campo personalizado com o código da campanha. Dispara o webhook e responde às consultas da API.

## API de Conversões do Meta

Recebe os eventos Compra com valor e Lead qualificado, com telefone com hash, valor e moeda, no conjunto de dados de cada cliente.

## Meta Events Manager

Valida os envios na aba Test Events e mostra a taxa de correspondência durante o piloto.

## Meta Business Manager

Dá à Arthea o acesso de parceiro para gerar o token da API de Conversões no conjunto de dados de cada cliente.
