# Imagens necessárias

Coloque aqui os seguintes arquivos para o site ficar idêntico ao original do Lovable:

| Arquivo                | O que é                                                   |
| ---------------------- | --------------------------------------------------------- |
| `hero-embrace.jpg`     | Pintura clássica de um casal abraçado (hero + CTA final). |
| `painting-couple-1.jpg`| Pintura de casal usada na seção "Nunca se falou tanto..." |
| `painting-couple-2.jpg`| Pintura "O Beijo" (Hayez) — seção "A maioria das histórias". |
| `andre.jpg`            | Foto do André (sorrindo, fundo escuro).                   |
| `consultorio.jpg`      | Foto do consultório (2 poltronas, parede azul).           |

Sugestões enquanto não tem os finais:

- Para as pinturas clássicas: baixe os arquivos em domínio público no Wikimedia Commons
  (Francesco Hayez — "Il Bacio"; outras românticas do séc. XIX).
- Para a foto do André e do consultório: use as mesmas que estão no site atual da Lovable
  (clique direito → salvar imagem como).

Resolução recomendada: largura mínima de 1600px para `hero-embrace.jpg`,
1200px para as demais. Salvar como JPG otimizado (~200–400 KB).
